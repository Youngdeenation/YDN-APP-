# YDN App

**YDN App** is a prototype social media platform designed for Android. It features a clean dark mode UI and core features similar to Instagram or TikTok.

## Features

- User authentication (Login & Signup)
- Feed with image and video posts
- Like, comment, and share buttons
- Chat screen (placeholder)
- Notifications screen (sample content)
- Minimalist dark mode UI
- Built using Flutter with dummy data
